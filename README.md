# CraftPanel – pobieranie i aktualizacje

Natywna aplikacja macOS do stawiania i zarządzania lokalnymi serwerami Minecraft (Apple Silicon + Intel, macOS 13+).
To repozytorium zawiera **tylko gotowe wydania aplikacji** – nie ma tu kodu źródłowego.

## Pobranie i uruchomienie
1. Wejdź w [Releases](../../releases/latest) i pobierz `CraftPanel-<wersja>.zip`.
2. Rozpakuj i przeciągnij `CraftPanel.app` do folderu **Programy**.
3. Pierwsze uruchomienie: kliknij aplikację prawym przyciskiem → **Otwórz** → **Otwórz** (aplikacja nie jest jeszcze notaryzowana).
4. Reszta (Java, serwer Paper/Fabric/Vanilla, EULA) instaluje się z poziomu aplikacji – bez Terminala.

## Aktualizacje
Aplikacja sama sprawdza plik `latest.json` z tego repozytorium i informuje o nowej wersji
(w *Ustawienia → Aktualizacje* można wyłączyć powiadomienia lub sprawdzić ręcznie).
